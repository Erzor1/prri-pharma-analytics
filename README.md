## 📌 О проекте и его практической пользе

Каждый месяц Росздравнадзор отзывает из аптек и больниц десятки серий лекарственных препаратов. Для **аптечных сетей, дистрибьюторов и отделов госзакупок** каждый такой отзыв означает прямые убытки: заморозку товара на складе, расходы на обратную логистику и риск срыва контрактов. Для **фармпроизводителей (R&D и службы качества)** — это потеря репутации и миллионные списания сырья.

**В чем проблема обычной статистики?**  
Если оценивать производителей просто по количеству отозванных серий, то в один «черный список» попадают:
- Завод, у которого на 100 пачках витаминов обнаружилась мелкая опечатка в шрифте на коробке (при этом сами таблетки полностью качественные);
- Завод, у которого в 15 сериях жизненно важного препарата разрушилось действующее вещество, выросли токсичные примеси или таблетка перестала растворяться.

**Что сделано в этом проекте:**  
Мы собрали живые данные Росздравнадзора за **2020–2026 годы (`10 052` записей по `367` заводам)** и разработали понятную систему скоринга риска **PRRI (Pharma Recall Risk Index)**. Она автоматически отделяет безобидные ошибки упаковки от опасного технологического брака и помогает бизнесу принимать решения о закупках на основе данных.

## 📊 Описание данных

Данные загружаются напрямую из официального сервиса Росздравнадзора [«Поиск изъятых из обращения лекарственных средств»](https://roszdravnadzor.gov.ru/services/lssearch):

* `trade_name` — торговое наименование препарата;
* `dosage_form_raw` — лекарственная форма, дозировка и фасовка;
* `batch_number` — номер забракованной серии;
* `manufacturer_raw` — производитель и страна производства (`country`);
* `status` и `regulatory_action` — статус препарата и принятая мера (`Отзыв`, `Прекращение обращения`, `Приостановление`, `Изъятие`);
* `letter_raw` и `letter_link` — номер, дата письма Росздравнадзора и прямая ссылка на оригинал PDF-документа;
* `defect_parameter` — конкретный показатель брака по результатам лабораторной экспертизы (`Растворение`, `Родственные примеси`, `Описание`, `Количественное определение`, `Микробиологическая чистота`, `Маркировка` и др.).

**Важная деталь очистки данных:** из расчетов риска полностью исключены `208` писем со статусом `Разрешение реализации` — это письма о снятии карантина и возврате качественных серий в продажу после перепроверки.

## 🧮 Как считается индекс риска PRRI (простыми словами)

Для каждой забракованной серии мы перемножаем **4 понятных фактора**:

$$\text{PRRI} = \sum \left( W_{\text{тяжесть}} \times W_{\text{мера}} \times W_{\text{повторы}} \times W_{\text{свежесть}} \right)$$

1. **Тяжесть брака ($W_{\text{тяжесть}}$):**
   - **Уровень 1 (вес `1.0`) — Только упаковка:** проблемы с маркировкой, этикеткой или пачкой. Сама таблетка безопасна.
   - **Уровень 2 (вес `2.5`) — Технологический брак формы:** таблетка не растворяется вовремя, крошится, изменила цвет или в ампуле видны механические частицы.
   - **Уровень 3 (вес `5.0`) — Критическая угроза здоровью:** в препарате выросли токсичные примеси распада, нарушена дозировка действующего вещества или препарат нестерилен.
2. **Строгость меры ($W_{\text{мера}}$):** полный отзыв или изъятие из аптек получает вес **`1.5`**, временная приостановка — **`1.0`**.
3. **Штраф за системность ($W_{\text{повторы}}$):** если у завода раз за разом бракуют серии по одной и той же технологической причине, включается повышающий коэффициент — это сигнал, что на производстве системно не отлажена технология.
4. **Свежесть инцидента ($W_{\text{свежесть}}$):** забраковки за последние **12 месяцев** учитываются в полном объеме (вес `1.0`), а старые ошибки 3–5-летней давности постепенно теряют вес, чтобы рейтинг отражал текущее качество завода.

Дополнительно для каждого завода считается **TDR (Technological Defect Share, %)** — доля реального технологического и химического брака (Уровни 2 и 3) без учета опечаток на упаковке.

## 💡 Главные выводы и инсайты исследования

1. **Как метрика `PRRI × TDR` спасает от ошибочной блокировки поставщиков (кейс «Юнифарм Инк»):**  
   У компании «Юнифарм Инк» в базе числится **135 отозванных серий**. В простом отчете по числу серий этот поставщик попал бы в топ худших компаний рынка. Однако наша модель показывает, что **все 135 серий (100%) были отозваны только из-за маркировки и упаковки (`TDR = 0%`)** — к самим препаратам претензий нет. В то же время у лидеров антирейтинга (`ООО «ПРАНАФАРМ»`, `ПАО «Биосинтез»`, `АО «ВЕРОФАРМ»`, `ООО «Озон»`) доля технологического и химического брака превышает **96–99%**.
2. **Закон Парето на фармрынке:**  
   Всего **12 заводов из 367 (3.3% производителей)** создают около **60%** всего технологического риска забраковок на рынке РФ.
3. **Причины брака российских и импортных лекарств кардинально отличаются:**  
   У импортных лекарств **35.1% всех проблем — это упаковка и маркировка** (ошибки перевода пачек и инструкций при локализации), а технологический брак формы составляет лишь **14.6%**. У российских заводов проблемы с упаковкой встречаются вдвое реже (**15.9%**), зато **38.6%** приходится на технологический брак самой таблетки или ампулы (растворение, описание, механические включения).
4. **Таблетки и капсулы (ТЛФ) — самая сложная и уязвимая форма выпуска:**  
   В твердых лекарственных формах доля технологического и химического брака достигает **83.9%** (главные проблемы — рост примесей распада `32.6%` и плохое растворение таблетки `20.0%`). Для сравнения: в нестерильных жидкостях (сиропы, капли, растворы) почти половина всех отзывов (**42.9%**) связана просто с этикеткой и коробкой.
5. **Хронические рецидивы конкретных препаратов:**  
   Анализ повторных писем РЗН выявил препараты, которые годами отзываются по одной и той же причине из-за нестабильности рецептуры при хранении: например, *«Эналаприл»* (ПАО «Биосинтез» — **47 писем РЗН / 108 серий** по родственным примесям), *«Ундевит»* (АО «Алтайвитамины» — **27 писем / 67 серий** по падению содержания витаминов), *«Цитрамон П»* (ОАО «ДАЛЬХИМФАРМ» — **25 писем** по распаду ацетилсалициловой кислоты до салициловой кислоты) и *«Спиронолактон»* (ООО «ПРАНАФАРМ» — **19 писем / 32 серии** по нерастворению капсул).

## 🧪 Результаты статистической проверки гипотез (`scipy.stats`)

Все ключевые наблюдения проверены статистическими тестами на уровне значимости $\alpha = 0.05$:

| № | Что проверяли | Метод | Результат ($p\text{-value}$) | Итог | Суть вывода |
| :-: | :--- | :--- | :--- | :--- | :--- |
| **1** | Различается ли структура брака у российских и импортных лекарств? | Критерий $\chi^2$ Пирсона | $p = 2.65 \times 10^{-64}$ | **Подтверждено** | Импорт чаще бракуют за упаковку (35.1%), а российские ЛС — за технологию самой формы (38.6%). |
| **2** | Зависит ли доля тех. брака (`TDR`) от вида лекарственной формы? | Критерий $\chi^2$ Пирсона | $p = 4.10 \times 10^{-34}$ | **Подтверждено** | Таблетки и капсулы значительно чаще имеют технологический брак (83.9%), чем жидкие формы (57.1%). |
| **3** | Выше ли индекс риска `PRRI` у отечественных площадок по сравнению с импортными? | $U$-тест Манна-Уитни | $p = 0.0006$ | **Подтверждено** | Медианный индекс риска заводов РФ (`4.37`) в 2.7 раза выше зарубежных (`1.64`) из-за серийных повторов брака. |
| **4** | Есть ли сезонность по кварталам года в выходе писем Росздравнадзора? | $H$-тест Краскела-Уоллиса | $p = 0.5269$ | **Сезонности нет** | Между производством/перевозкой серии, отбором проб в аптеке и лабораторным анализом проходит **3–9 месяцев**, что полностью сглаживает сезонные пики. |

## 🎯 Практические рекомендации на основе анализа

1. **Для закупок (аптечные сети, дистрибьюторы, тендерные отделы):**
   - Разделять поставщиков из зоны `Packaging Risk` (проблемы только с коробкой) и `Critical Tech Risk` (проблемы с субстанцией и растворением).
   - Не закупать длинный складской запас по препаратам-рецидивистам из зоны критического риска (так как из-за химической нестабильности рецептуры новые серии с высокой вероятностью снова попадут под отзыв РЗН через 6–12 месяцев хранения).
2. **Для технологов R&D и отделов качества фармпроизводителей:**
   - При выпуске таблеток и капсул с плохо растворимыми субстанциями (спиронолактон, ибупрофен) контролировать размер частиц субстанции ($d_{90}$) при каждой смене поставщика сырья.
   - Для чувствительных к влаге препаратов (эналаприл, цитрамон, каптоприл) переходить с обычной ПВХ-пленки на влагозащитные блистеры (`Ал/Ал` или `ПВХ/ПВДХ`) и жестко контролировать остаточную влагу гранулята перед таблетированием.

## 🖥️ Интерактивный веб-дашборд и структура проекта

Веб-приложение на **Streamlit + Plotly** (`app.py`) включает 4 вкладки:
1. **Executive Summary & KPI** — общая сводка, помесячная динамика, структура причин брака и живой поиск по всем препаратам.
2. **Скоринг производителей (PRRI)** — сравнение заводов, кривая Парето и **интерактивное досье каждого из 367 производителей** с круговым профилем дефектов и прямыми ссылками на скачивание оригинальных PDF-писем Росздравнадзора.
3. **Технологический R&D-анализ** — тепловая карта «Лекарственная форма × Дефект», витрина хронических рецидивов и разбор реальных производственных кейсов.
4. **Стат. гипотезы и методология PRRI** — интерактивный калькулятор-симулятор расчета индекса `PRRI` и результаты статистических тестов.

### Структура папок
```text
PRRI/
├── .github/workflows/deploy.yml     # Автодеплой на VPS при пуше в ветку main

├── notebooks/
│   └── eda_and_hypotheses.ipynb     # Блокнот с предобработкой, EDA, графиками и стат. тестами

│   ├── scraper.py                   # Парсер живого API Росздравнадзора
│   ├── cleaner.py                   # Очистка данных, классификация дефектов и расчет PRRI
│   ├── database.py                  # Работа с БД (PostgreSQL 16 / SQLite)
│   ├── stats_tests.py               # Модуль статистических тестов (scipy.stats)

```

## 🚀 Как запустить проект

### Запуск через Docker Compose (PostgreSQL 16 + Дашборд)
```bash
git clone https://github.com/Erzor1/prri-pharma-analytics.git
cd prri-pharma-analytics
docker compose up -d --build
```
После сборки дашборд будет доступен в браузере по адресу `http://localhost:8501`.

### Локальный запуск через Python
```bash
python -m venv .venv
.\.venv\Scripts\activate      # Для Windows (или source .venv/bin/activate для Linux/Mac)
pip install -r requirements.txt

python -m src.pipeline        # Выгрузка данных, расчет метрик и создание SQL-витрин
streamlit run app.py          # Запуск веб-дашборда
```
